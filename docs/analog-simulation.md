# アナログ回路と解析

本パッケージは回路図を編集するための20種類の部品と、直流動作点・単一周波数の小信号交流・時間領域の過渡解析を提供します。解析は学習や回路の概算向けです。SPICE系シミュレーターの詳細なデバイスモデルや製品設計用の精度を提供するものではありません。

## 部品と数値プロパティ

部品カタログは次の20種類です。部品の追加時の初期値と端子名は `circuitPartCatalog`、編集可能な数値フィールドと範囲は `circuitPartNumericFields(kind)` から参照できます。UIの部品プロパティとプレビューはこのメタデータを使います。

| 種類 | 数値プロパティと既定値 |
| --- | --- |
| 電池 | `voltageVolts` 9 V、`internalResistanceOhms` 0 Ω |
| 抵抗 | `resistanceOhms` 10 Ω |
| 電球 | `resistanceOhms` 20 Ω、`ratedPowerWatts` 2 W |
| スイッチ | 初期状態は閉。操作時に状態を切替 |
| 電流計・電圧計・接続点 | 追加の数値プロパティなし |
| 交流電源 | `voltageVolts` 5 V RMS、`frequencyHz` 1000 Hz、`phaseDegrees` 0°、`offsetVolts` 0 V |
| コンデンサ | `capacitanceFarads` 1 µF、`initialVoltageVolts` 0 V |
| コイル | `inductanceHenries` 0.01 H、`initialCurrentAmps` 0 A |
| GND | 追加の数値プロパティなし。すべてのGND端子は同じ0 V基準 |
| 電流源 | `currentAmps` 0.01 A。正の値はA端子からB端子へ流れる向き |
| 可変抵抗 | `resistanceOhms` 1000 Ω、`wiperPosition` 0.5。A–C間の抵抗は全抵抗×位置 |
| ダイオード | `saturationCurrentAmps` 1 pA、`emissionCoefficient` 1 |
| LED | `saturationCurrentAmps` 1e-20 A、`emissionCoefficient` 2、`ratedCurrentAmps` 20 mA |
| NPN・PNPトランジスタ | `currentGain` β 100、`saturationCurrentAmps` 10 fA |
| N・PチャネルMOSFET | `thresholdVolts` 2 V、`transconductanceAmpsPerVoltSquared` 0.02 A/V²、`channelLengthModulation` 0.01 1/V |
| オペアンプ | `openLoopGain` 100000、`positiveRailVolts` +15 V、`negativeRailVolts` −15 V |

電池、抵抗、電球、スイッチ、電流計、電圧計、接続点の従来7種類は既存の直流解析経路で処理します。この7種類だけを使う既存回路では、導線・閉スイッチ・電流計の1e−6 Ω近似を維持し、電池の内部抵抗には1e−6 Ωの下限を適用します。閉スイッチと電流計の `powerWatts` には、この近似抵抗による消費電力も含めます。高抵抗回路でも電位差や微小電流を桁落ちで失わないよう計算します。短絡判定は外部負荷の合成抵抗が1e−3 Ω未満かで行い、直列・並列接続した電池では電源群に接続された負荷網の合成抵抗を考慮します。その他の部品や交流モードはアナログ解析経路を使います。

同じ部品の異なる端子間にも導線を接続できます。抵抗をバイパスする配線や電池の短絡も回路データとして表現でき、編集・保存・読み込みで同じ接続を保持します。短絡の影響は解析結果と診断で確認してください。同じ端子から同じ端子への導線と、向きを問わず同じ端子間を重複して接続する導線は入力不正です。異なる端子対を結ぶ導線が作るループは表現できます。

## 定常解析

`analyzeCircuit(document, switchStates?, options?)` の `options.mode` は `"auto"`、`"dc"`、`"ac"` です。`auto` は交流電源を含む回路を交流解析、それ以外を直流解析にします。`frequencyHz` は小信号交流解析の周波数です。未指定なら回路内の最初の交流電源の周波数を使い、電源がなければ1 kHzを使います。

解析APIには、`CircuitDocument`、各部品・導線、スイッチ状態、解析optionsとして、`Object.prototype` または `null` をプロトタイプに持つデータオブジェクトを渡してください。own data propertyは非列挙でも検証・保持します。getter/setterを持つこれらのレコードやクラスインスタンスは入力不正として扱います。`parts` と `wires` は穴のない通常の配列で指定してください。要素にgetter/setterを持つ配列、独自のプロパティ、独自prototype、または `map`・`entries`・iteratorなどの上書きを持つ配列も入力不正として扱い、accessorは実行しません。

```ts
import { analyzeCircuit, createCircuitExample } from "@nodemy-official/circuit-module";

const circuit = createCircuitExample("ac");
const analysis = analyzeCircuit(circuit, {}, { mode: "ac", frequencyHz: 1000 });
const capacitor = analysis.parts.load;
console.log(analysis.mode, analysis.frequencyHz);
console.log(capacitor.voltageVolts, capacitor.voltagePhaseDegrees);
```

交流結果の `voltageVolts` と `currentAmps` は実効値の大きさで、符号を持ちません。`voltagePhaseDegrees` と `currentPhaseDegrees` が基準に対する位相、`reactivePowerVars` が無効電力です。`analyzeCircuit()` の `powerWatts` は受動部品で吸収を正、解析中に励振する電源で供給を正にします。交流解析で電池は励振せず、内部抵抗による吸収を正にします。損失のない理想コンデンサ・コイルの定常解析では有効電力を0 Wとして扱います。直流結果は電圧・電流が符号付きです。部品の主計測値は、BJTでコレクタ−エミッタ、MOSFETでドレイン−ソース、オペアンプで出力−GND、可変抵抗でA−B間を表します。個々の端子値は `terminalVoltages` と `terminalCurrents` で参照できます。

アナログ解析では抵抗・電球・可変抵抗、および交流のコンデンサ・コイルの枝電流を原則として未知数に取り、部品の電圧降下をインピーダンスと電流から求めます。リアクタンスやアドミタンスが `number` の表現範囲を外れても、内部の有理数から回路方程式を組み立てます。抵抗比が大きい回路でも、ほぼ等しい端子電位の引き算で微小な電圧降下を失いにくくするためです。電源電圧と内部抵抗の降下がほぼ相殺して枝電圧が崩れる場合は、より誤差の小さい回路経路上の枝電圧を合算して復元します。部品の測定値には主計測値を使ってください。`terminalVoltages` を利用側で引き算すると、浮動小数点数の丸めにより小さな差が失われる場合があります。未接続部分の仮の基準電位は独立して固定し、別の正常な回路の計算を妨げないようにしています。

アナログ解析の線形方程式では、有限なJavaScript `number` をそのbinary64値と等しい正確な二進有理数として扱います。行列・右辺の組み立てと内部状態の更新でも有理数を保持し、密行列はBigInt整数の分数なし消去法（Bareiss法）、疎行列は疎な有理数消去法で解きます。消去・後退代入・内部状態の引き継ぎでは浮動小数点へ丸めず、解析結果を `number` として返す時点でbinary64へ丸めます。複素値の振幅は正確な実部・虚部の二乗和からBigInt整数平方根で求め、最後に一度だけ丸めます。位相は実部・虚部を有理数で正規化してから計算し、小さな角度は比から度を直接求めることで、途中積のoverflow・underflowやラジアン表現で0になる角度を避けます。BJTでは各接合の電流・勾配を指数モデルから求める段階（指数関数、乗除算、線形継続）がbinary64近似の境界になり、その後の端子電流と小信号ヤコビアンの積和は有理数で保持してから丸めます。厳密な有理数を保つ処理は長い過渡解析で分子・分母が増大し、浮動小数点だけの計算より時間・メモリを要する場合があります。ただし、係数を作る式や `Math.PI` などの数学定数、`atan2` は計算時点でbinary64近似になり、最終値の丸めと表現範囲の制限も残ります。非線形部品モデルや反復の収束許容差、過渡解析の後退Euler法による離散化誤差も別に残るため、解析全体の誤差がなくなる保証ではありません。

理想AC電圧源の閉ループでは、指定された振幅・度単位の位相を厳密な入力として照合します。同一方向の振幅は符号付きで合算し、三角係数にはMachin式のπと固定小数Taylor展開による近似値・誤差上限を使います。基本精度は512 bitで、振幅の指数差、微小な位相間隔、異なる位相の数に応じて増やします。三角近似の誤差上限を超える不整合は、表示用の矩形値では同じ値に丸められても `invalid` です。矩形電圧を `hypot`・`atan2` で丸めた極座標へ変換すると、元の矩形値が整合していても冗長な理想電源の指定値が矛盾する場合があります。軸上の係数は厳密です。通常のAC行列係数と表示値には引き続きbinary64の三角近似を使い、電源ループの照合精度とは区別します。

スイッチ部品の `CircuitPartReading` と `TransientPartReading` には `switchClosed` が付き、解析で使った閉・開状態を示します。`analyzeCircuit()` の `switchStates` 引数、または `simulateTransient()` の `options.switchStates` に指定した上書きを優先し、上書きがない場合は部品の `initiallyClosed` を使います。過渡解析では各サンプルのスイッチ状態を参照できます。解析パネルの時間波形も表示中の定常解析結果のスイッチ状態を引き継ぎます。定常解析で使う状態が変わると現在の時間波形を消去し、再計算が必要になります。

MOSFETの計測値には `channelConducting` が付き、モデル上のチャネルに電流または微分応答があるかを示します。直流では動作点、交流では線形化に使った直流動作点、過渡解析では各サンプルの状態を使います。ドレイン電流が0 Aでも微分応答があれば `true` です。完全に遮断したチャネルを電流の戻り道や電位の基準を結ぶ経路として扱いません。外部の回路にも電位を定める経路がないドレインは浮遊し、そこを測る電圧計は `floating` になります。測定値の利用可否は引き続き `meterStatus` と解析全体の `status` で判断してください。

交流の部品読み取りには `acReferenceTerminalGroups` と `acCurrentResponseTerminalGroups` が付きます。前者は直流動作点で線形化した小信号モデルを通じて電位の基準を共有する端子グループ、後者は端子電流の微分応答が結び付ける端子グループです。空配列 `[]` はそれぞれのモデルについて対応する結び付きがないことを表し、未指定は従来の部品別ルールを使います。2つのグループは別の量を表します。たとえば、ダイオードの逆バイアスで端子電流の微分値が0なら、両方のグループは空です。一方、MOSFETはチャネル長変調が0でもゲート制御による電流応答が残ることがあり、その場合に電位の基準グループと電流応答グループは異なります。BJTも片方の接合電流だけが微分応答を持つとき、電流応答グループは応答する端子対を示します。電圧計や電位表示は基準グループを使い、AC回路の戻り経路判定は電流応答グループを使います。

電位可視化APIの `CircuitPotentialContext` は、同じcontextを再利用してドキュメント・解析結果・ノードをインプレース更新しても、新しい電位差を計算します。

3端子部品の読み値と過渡サンプルには、任意の `terminalVoltageDifferences` が含まれます。各要素は `fromTerminal`、`toTerminal`、`voltageVolts`、交流では `voltagePhaseDegrees` を持ち、内部の端子電位が表示用に丸められる前に差を計算します。電位可視化はこの値を使うため、可変抵抗の電流表示が0 Aへunderflowしても分圧を保持し、MOS・BJTの大きな共通電位上の局所電圧も失いません。この情報はJSON複製後も利用でき、内容を更新すると電位経路のキャッシュも更新されます。

開いたスイッチの電位差にも、解析で計算した部品電圧を使います。両端子の電位表示が同じ値に丸められても微小な電圧差を保持します。端子が同じ電位基準を共有することの確認は、スイッチの状態によらず行います。

AC電源と電位表示の極形式からの変換は共通の `complexFromPolar` を使います。通常の三角関数係数はbinary64近似ですが、振幅との積は有理数で保持し、極小振幅を実部・虚部へ投影してから計算へ戻しません。軸からの位相差が1e−7度未満ならsin εをε、cos εを1として、ε = 位相差 × π / 180も有理数で保持します。この係数近似の誤差はε² / 2未満（1.6e−18未満）です。電位経路の加算・反転・差とノード電流の合計にも共通の複素演算を使い、途中のunderflowを引き継がないようにしています。

45度の対角方向には、√(1/2)を2^512倍して切り下げた有理数係数を両成分へ使います。係数の絶対誤差は2^−512未満で、対角位相の対称性を維持します。係数の整数値nはn² ≤ 2^1023 < (n+1)²で独立に確認できます。方向係数の二乗和の逆数も保持し、入力したRMS振幅を方向近似の長さで変えないようにします。同じ補正を共有する応答群では、電圧・電流の振幅と厳密な電力へ共通補正を適用し、最後に丸めます。応答群は共有接続点を境に分離でき、独立した別電源の追加でも既存回路の補正を保ちます。制御部品の非ゼロヤコビアンも含め、オペアンプやMOSの入力から出力へ補正を伝えます。開スイッチ・電圧計・遮断MOSなどの両端が同じ応答群に属する場合も、共有電位を合成する前の厳密な局所差へその群の補正を適用します。3端子の局所差はアナログ読み値から保持し、JSON復元後の電位表示にも使います。これにより、大きな共有電位上でも微小な分圧の最近接・偶数丸めを保ちます。最小正数の電源に2 Ωを接続した電流表示は、独立なオームの法則と偶数丸めから0 Aになりますが、内部の非ゼロ電流と位相は保持されます。

異なる補正を持つ交流電源が同じ応答群で作用する場合は、各補正の平方根を有理数へ展開してから回路方程式を組み立てます。既約な分子・分母がともに完全平方なら、平方根を厳密な有理数として保持し、後続の中点の偶数丸めを変えません。それ以外の基準の相対精度は512 bitです。補正の大きさと1からの偏差を有理数のまま調べ、小数部の精度pを増減します。平方根の絶対打切り誤差は2^−p未満で、平方根自身と1からの非ゼロの偏差それぞれに対する相対誤差も2^−512未満になります。これにより、極小の位相差を持つ同振幅の電源を引いても、固定小数部の切り下げ誤差を差電圧として残しません。異なる補正を持つ複素値の加減算では、各成分の大きさと二乗値の差から結果の下限を求め、必要ならpをさらに増やします。非ゼロの成分へ与える打切り誤差は、その合成結果の絶対値の2^−512倍未満です。符号と補正後の二乗値から厳密な相殺を確認できる成分は0とします。同じ補正の合成は係数を分離したまま行い、この打切りを加えません。理想AC電源の主RMS電圧は、指定した振幅を保持します。位相方向の通常の三角関数近似の誤差は別に残るため、回路の増幅が最終応答へ与える誤差は引き続きモデル境界として評価してください。

読み値には、丸めによって失われる成分がある場合に `exactVoltage`、`exactTerminalVoltages`、`exactTerminalCurrents` が付きます。直交成分を16進整数の分子・分母で保存し、必要なら振幅補正の二乗も保持します。電位経路の合計やノード電流のつり合いは、これらを復元してから計算します。`projection` は元の表示値を保持し、利用側が表示値だけを編集した場合はその編集を優先します。JSON保存・復元や `structuredClone` でも精度情報は維持されます。

長い過渡解析で分数が4096 bit以上になる場合は、読み値から解析結果の `precisionExpressions` 内の演算式を参照します。この閾値は保存形式を選ぶためのもので、計算精度や小さな値の扱いは変えません。依存式を共有し、同じ巨大な分子・分母を全サンプルへ繰り返し保存することを避けます。各式は有理数の加減乗除・総和から厳密値へ復元でき、丸めや近似は加えません。過渡フレームへは解析結果とサンプル番号を渡し、式表も保持してください。式表は読み取り専用です。保存後の結果を編集する場合も式表をその場で書き換えず、表全体を置き換えてください。

整数消去を通る非線形解析でも、共通分母で整数化する前の右辺を演算式として追跡します。履歴依存の巨大な共通分母を式へ重複保存せず、検証済みの解へ対応する式を保持します。式の復元は最大32件の中間値を再利用し、長い依存関係を再帰なしで評価します。不正な参照・分母などの任意精度情報は無視し、表示値へフォールバックします。過渡フレームの活動判定も、外部の符号情報だけを信頼せず復元値を検証します。両端子が同じノードへ直接接続されたダイオード・LEDは回路方程式へ非線形応答を与えないため、そのほかが線形なら線形解析経路を使います。素子のスタンプと読み値は維持します。

低レベルAPIでは電力の符号規約が異なります。`analyzeAnalogCircuit()` / `solveAnalogStep()` の `power.real` と、`simulateTransient()` が返す各サンプルの `powerWatts` はすべての部品で吸収を正とし、電源などが供給すると負になります。直流・過渡結果の電圧と電流は符号付きで、通常はA−B電圧とA端子へ流入する電流を表します。BJTはC−E・C端子へ流入、MOSFETはD−S・D端子へ流入、オペアンプは出力−GND電圧・出力端子へ流入する電流です。

回路全体の `analysis.currentAmps` は、単一の独立電源について電流を定義できる場合に限り値を持ち、複数電源やオペアンプを含む回路では `null` です。オペアンプの簡易モデルでは正負電源レールを内部で参照し、回路図上の独立電源として扱わないため、電源電流を1つの値にまとめられません。解析パネルでは値がない場合「—」を表示します。

定常解析の `status` は計算の成否だけでなく、回路の戻り経路も表します。独立電源からその電源自身を通らずに戻る経路がなければ、有効な電圧を計算できても `open` になります。独立電流源が別々の電位基準島をつなぐ場合は、各島に流れ込む電流と流れ出る電流が釣り合えば解析できます。釣り合わない島では `invalid` となり、電位差を測る電圧計は島をまたぐと `floating` になります。直流定常解析ではコンデンサを開放として扱うため、RC充電例は定常解析で `open`・0 Aとなりますが、同じ回路の `simulateTransient()` は充電中の有効な時間波形を返します。交流解析ではコンデンサとコイルが周波数に応じた経路になり、オペアンプ回路は出力端子からGND（GNDがない場合は解析基準点）への外部負荷経路があると `closed` になります。過渡解析のフレーム表示では、各サンプルのスイッチ・MOSFET状態とコンデンサ電圧・コイル電流を使って戻り経路を判定します。独立電源や蓄積エネルギーが経路につながる場合、またはオペアンプ出力に基準点までの負荷経路がある場合は `closed` です。励振源や蓄積エネルギーの戻り経路がすべて開スイッチなどで切れていれば `open`、それらもオペアンプ出力経路もなければ `idle` です。このためRC充電中や電源のないLC放電中は `closed` になります。

交流解析は1周波数ずつ計算します。選んだ解析周波数と一致しない交流電源は、その計算では励振されず診断に表示されます。周波数値の浮動小数点の丸め程度の差は、同じ周波数として扱います。電流源は直流専用で、小信号交流解析時に励振電流を与えません。コンデンサとコイルは周波数に応じた複素インピーダンスとして計算します。半導体の交流結果は直流動作点まわりの小信号線形化です。

## 数値計算の再発防止

線形ソルバーは解を返す前に、元の行列と右辺に対して `A × x = b` が厳密に成り立つことを有理数で検査します。許容差を設けず、binary64では0になる微小な残差も拒否します。複素系は実数系への変換とは別に元の複素方程式を検査します。逆行列キャッシュの解にも同じ検査を行い、不一致ならそのキャッシュを破棄して通常の検証付き解法に戻します。この検査が保証するのは組み立て済みの方程式との整合性です。線形解法と共有する有理数演算そのものの誤りや、部品モデル・方程式組み立ての正しさは、独立オラクルと回路不変条件のテストで補います。

長い過渡履歴で整数が大きくなる場合も、分子・分母を丸めずに計算します。整数除算では上位ビットから商の候補を求め、元の整数で `N = qD + r` と `0 ≤ r < D` を満たすことを確認してから採用します。確認できなければ通常の整数除算へ戻るため、この高速化に近似誤差はありません。方程式の検査も、正の共通分母を厳密に取り除いてから等式を比較し、微小な非ゼロ残差を引き続き拒否します。巨大整数と小さい除数の最大公約数は、変更不能な整数の組を件数上限付きで再利用します。

開発時は `bun run check:numerics` で数値契約の検査を実行できます。通常の `bun run check` とCIにも含まれます。型情報を用いる静的検査は、低層の `exact-numeric-state.ts` と `exact-linear-algebra.ts` を除く `src/` 本体で、`Float64Array` と型判定された値への添字代入・複合代入・`++` / `--`、`set` / `fill` / `copyWithin` / `reverse` / `sort`、`slice` / `map` / `filter` / `subarray` / `toReversed` / `toSorted` / `with`、`new Float64Array(existing)`、標準constructorの `Float64Array.from(existing)` / `Array.from(existing)`、spreadを検出します。検査対象はこれらの型と構文に限られ、`buffer` や `Reflect` 経由の操作、任意の関数間にまたがるデータフローを証明するものではありません。状態は `setRealStateValue` / `addRealStateValue` で更新し、`cloneRealState` で複製してください。

演算基盤には、本体の算術関数を使わない有理数オラクルで最終丸めを調べる生成テストを追加しています。サブノーマル値、極端な指数、巨大項の相殺などを固定したseedで再現し、結果と隣接するbinary64値の中点から最近接・偶数丸めを検査します。既存の回路オラクル・KCL・スケール変換テストと併用します。指数・三角関数、非線形収束、時間刻み、表示用の最終丸めの誤差は、引き続きそれぞれのモデル・用途に応じて評価する必要があります。

BJT・MOSFETの局所的な端子間電圧は、有理数で差を完成させてからデバイスモデルへ渡します。BJTの指数評価と、通常のMOSFETの過駆動電圧・チャネル電圧のモデル評価はbinary64近似の境界です。MOSの制御電圧をbinary64に投影した絶対値が2^−1022未満の場合は、指数を制限せず仮数を512 bitの最近接・偶数丸めにします。制御電圧の相対誤差は2^−512以下で、表示値が0でも増幅後の有限な電流を保持します。同じ境界値をNewton法の線形化基準にも使用します。仮数長を制限することで非線形反復の分母の増大を避け、モデル係数の積和と回路方程式では再び有理数を保持します。オペアンプの利得・レール制限・出力抵抗の計算は内部状態の厳密値を使い、丸められた出力電圧と目標電圧の差から微小電流を失わないようにしています。

BJTの前向きベース電流は、接合モデルで保持した輸送電流を厳密な電流増幅率βで除算します。βが1未満でも、飽和電流を先にβで除算して表示用の値へ丸めません。輸送勾配がsubnormalの場合は、指数関数の係数から `Is·exp(Vbe/Vt)/(β·Vt)` を有理数で求め、βによる増幅後の微分応答を保持します。深い逆バイアスで指数係数自体がunderflowする場合は、飽和電流とβの厳密な比の対数を使って指数をまとめます。この経路の `log` と `exp` はbinary64近似の境界で、評価後の積和は厳密値を使います。

オペアンプの帰還がBJTなどの非線形部品を通る場合、線形化した初期推定では帰還経路が開放され、過大な出力推定からNewton法が収束できないことがあります。BJTを含む回路で線形初期出力がレール外の場合、または線形初期解が特異な場合は、低いゲインで非線形帰還を解き、ゲインを倍増しながら得た厳密な状態を次の初期推定に使います。途中のモデルは初期推定だけに使い、最後は元のゲインとレールを持つ回路を解きます。通常の初期推定で収束しなかった場合は、独立電圧源のバイアスからも再試行します。いずれも元の部品モデルと物理残差・KCL/KVLの検証を満たす必要があります。

ダイオード・LED・BJTの接合で `|V/(n·Vt)| < 2^-1022` の場合は、`expm1(x)` を `x` と近似し、傾き `Is/(n·Vt)` と電流 `Is·V/(n·Vt)` を有理数で保持します。この線形近似の相対誤差は `2^-1023` 未満です。微小な制御電圧を先に表示値へ丸めて、増幅後なら表現できる電流を失うことを防ぎます。Newton法の線形化基準も同じ厳密な制御電圧を使い、モデル電流と回路方程式の整合性を保ちます。勾配がbinary64で0になる場合も、直流・過渡解析の電流は有理数で保持し、抵抗負荷の電圧や定格比を求める前に失わないようにします。小信号経路はこの場合に従来どおり開放として扱い、勾配が有限値の範囲を超える場合は解析不能とします。通常の電圧域は従来の指数モデルとbinary64近似を使います。

通常の指数域でも、接合電流がサブノーマルになる場合はbinary64で評価した `expm1` の係数と `Is` の積を有理数で保持します。指数評価の近似誤差は残りますが、積を表示用の電流へ丸めることによるKCLやLEDの定格比の欠落を防ぎます。電球とLEDの明るさも、電力・電流を表示値へ丸める前に定格値で割って求めます。電力・電流の表示が0になる場合でも、表現可能な明るさを保持します。従来の直流解析の電球過負荷警告も、厳密な電圧と電流の積を定格閾値と比較し、サブノーマルの丸めで警告を失わないようにしています。

ゲートをドレインまたはソースへ結んだMOSでは、電流0の遮断境界で勾配も0になり、Newton法がその根に近づき続ける場合があります。物理残差の検証時に部品ごとの厳密な境界候補を試し、変わる方程式が厳密に0になる場合に限り採用します。隣接MOSの基準端子が動く場合は、その部品の局所電圧差を厳密に保って電位を伝え、直列の遮断境界を順序に依存せず検証します。共有帰路の節点では他部品の残差も残るため、帰路と残りの全方程式は既存の物理残差・相対KCL/KVL検証に通す必要があります。電流が流れる別のMOSや電圧で固定された端子を一括して遮断せず、独立回路の追加でも初期状態を保持します。収束許容差は変更しません。

遮断するゲートが別のMOSを制御する場合は、その出力枝も含む回路方程式を候補点で解き直します。補助的に固定した端子間差が厳密に指定の境界値となり、補助電流が厳密に0の場合だけ、元の部品のKCL・KVLを検証して採用します。

ダイオード接続MOSを含む回路では、既知の初期コイル電流または独立電流源から、補助的な接続網でKCLを解いて初期電流の尺度を推定します。最初は単位コンダクタンスを使い、MOSの過駆動に対応する割線コンダクタンスと閾値の電圧オフセットで12回まで更新します。これにより、同じ直列枝の中でも係数が大きく異なる部品へ、適切な電流尺度を渡します。この接続網は初期推定だけに使い、元の抵抗・電源電圧・半導体のモデルを変更しません。入力電流を有理数で正規化し、補助電位は表示用の数値へ変換せず厳密解のまま扱うため、形式上の電位のoverflowで有限な局所解を失いません。同じゲート側節点と基準側節点を持つ並列チャネルはまとめて接続網へ入れ、それぞれの割線と閾値から分流を戻します。逆向きの候補は補助コンダクタンスを0にして次の推定へ進みます。

初期端子電位は補助網全体の解から整合させ、N・Pチャネルや弱い枝ごとに共有節点を上書きしません。応答するMOSの両端を更新し、解析基準点と独立した基準島の電位差を厳密に保ちます。実際の不均等な分流と遮断状態は元の回路方程式で解きます。両端が同じ節点の素子は電流推定の接続網から除外します。

電流と二乗則係数の比は有理数のまま平方根へ渡し、チャネル長変調による過大推定はモデル電流と照合して縮小します。電流分配、平方根と縮小のbinary64評価は初期推定だけの近似境界であり、誤差を最終解へ持ち込まず、元の方程式と既存の相対KCL・KVL検証を満たす必要があります。既知電流から推定できず初期Newton方程式が特異な場合は、有限の過駆動電圧を与える初期推定を一度試します。微小電流の残差が絶対許容差より小さいだけで反復を終了しないようにします。

従来の直流解析では、電池閉路の外部抵抗と短絡閾値の比較を有理数で行います。同一起電力の並列電池群は、各電池の正負端子の対応と直列中間抵抗を保った負荷網として解きます。複数の接続点を経由する循環でも並列群を合成し、単位起電力差による散逸電力から外部抵抗を求めます。合計起電力が厳密に0の循環は短絡としません。整合する直列電源群の負荷判定では電源電位の範囲を1 Vに正規化し、中間端子の弱い負荷や全導線も保持します。逆向きの電池の微小な起電力差も、実際の導線を辿って確認します。電池の内部抵抗は外部抵抗に含めないため、内部抵抗が有限でも、起電力の異なる電池を低抵抗の導線だけで並列接続した循環は短絡です。

短絡判定の電源群には閉路に参加する電池だけを含め、片端が開放された電池の追加で既存の負荷判定が変わらないようにします。また、他の電池によって端子電圧が相殺される場合があるため、単独電池の受動帰路は端子電圧と電池電流の比ではなく、受動負荷網の合成抵抗で評価します。整合する電池群でも、群全体の電位幅より低い起電力の電池には受動帰路の判定を残し、等価な電池経路の追加で局所的な短絡が隠れないようにします。

並列部分群の負荷判定では、実際の負荷端子から見た電源群の等価抵抗を使い、導線や両端の直列抵抗の分担、中間タップ、等価な直列電源経路を保持します。選択した電池群を理想電源として抑制した出力抵抗に共通負荷の抵抗を加え、開放時の等価起電力が厳密に0なら、その群が共通負荷を駆動する短絡とは判定しません。非選択電池は開放しますが、その電源を含む接続領域に残る受動的な接続は出力抵抗に保持します。電源の接続を追加した回路では、この領域と共通負荷との境界が変わる場合があります。各セルを1 Vにした総散逸の逆数だけで負荷抵抗を求めると、直列の起電力を誤って正規化したり、共通負荷を駆動しない局所損失まで合算したりするため、これらを負荷側の抵抗に混ぜません。負荷途中の端子を電源出力と誤認しないよう、元の直列列とセルの対応を保ち、両出力と選択電源が同じ二重連結成分にあること、同じ複数の電源枝が各出力へ内部の節点を共有しない経路で到達できることを確認します。この探索でも共有ハブや受動橋を一律に削除せず、実際の抵抗計算には全導線・タップ・私的シャントを残します。局所的な受動帰路と電源間の循環は別に検査します。負荷と直列抵抗の値が同じ場合も群を見失わないよう、抵抗値の部分網に加えて導線の分岐点間の接続経路を点検します。電源を含まない直列区間は一つの経路として扱い、並列負荷や分割した負荷でも端子の対応を維持します。

探索用の部分網で実際の出力端が電源列から離れた場合は、共通負荷を通らずに出力端から到達できる元セルのポートを使って直列列を復元します。複数段の共通負荷と私的シャントで列全体の候補が隠れる場合も扱うため、共通負荷を除いた電源側の部分網からも候補を発見します。復元した候補も、元の回路で出力境界と抵抗を検証します。確認済み候補の重複除去には、電池IDだけでなく各列の外側端子と所属セルも含め、同じセル集合の異なる直列分割を取りこぼさないようにします。

候補の境界証明は各列の対応ごとに行い、その後の同じ選択電池集合の出力応答と共通負荷抵抗を再利用します。出力応答の計算では、電流注入のない内部の葉を除き、2枝だけの節点で抵抗と向きを保った起電力を有理数のまま直列合成します。出力端子・分岐・並列経路は残します。また、全セルを理想短絡で抑制した電源側抵抗は、非選択セルを開放する各候補の抵抗の下限です。この下限と共通負荷抵抗の和が短絡閾値以上なら、その出力の群負荷探索を省きます。共通負荷は全並列経路で合成してから比較し、局所帰路と電源間循環は引き続き検査します。

弱い負荷によって電池端子が同じ導体成分になる場合は、受動枝の抵抗値ごとの部分網も点検し、負荷追加前から存在する低抵抗の循環を確認します。並列帰路の各枝は短絡閾値より大きくても合成抵抗が閾値未満になり得るため、点検の抵抗値を閾値で打ち切りません。同方向の並列電池群や分岐帰路では全受動枝を使った散逸電力も評価し、弱い負荷が閾値近傍の判定に与える影響を保持します。逆極性電源の循環では、その経路の抵抗と共通出力の負荷抵抗を別々に評価します。共通負荷の散逸を単位起電力差の循環へ合算せず、共通出力は開放電圧と出力抵抗・負荷抵抗の和で判定します。直列電池を含む帰路は元の電池端子の対応を維持して評価し、中間負荷も含めます。探索の抵抗下限にも成分間の受動枝を含め、これらの負荷で閾値未満になる候補を除外しないようにしています。

不整合な横断枝がある場合も、起電力と整合する帰路網を電位割当から探索します。同じ割当への到達順を重複除去し、未確定の全枝を含む抵抗の下限で候補を絞ります。基準電位と不整合な枝を通る必要がある帰路には、それら全枝の並列抵抗も下限として使います。下限計算では電流の流れない受動的な枝を除去し、開放抵抗を追加しただけで直列抵抗の下限や解析時間が崩れることを防ぎます。閉路の全列挙と特定の木への依存は使いません。

## 電流計・電圧計の読み値

基板上の電流計はA端子からB端子へ流れる電流を、電圧計はA端子とB端子の電位差を表示します。直流では符号付きで、端子の向きを逆にすると負の値になります。交流では単一周波数解析の実効値を表示します。モデル上、電流計は抵抗0 Ω、電圧計は回路に負荷を加えない理想計器です。ただし、従来7種類だけを使う直流解析では数値安定性のため、電流計を1e−6 Ωで近似します。読み値は数値解析の結果であり、末尾の桁が実測精度を表すものではありません。

各計器の解析値には `meterStatus` が付き、`connected` は両端子が接続され測定できる状態、`unconnected` は少なくとも片方の端子に導線がない状態、`floating` は導線があっても電圧の基準が定まらない、または電流計が迂回され電流を特定できない状態を表します。`unconnected` と `floating` の数値は有効な測定値として扱わず、回路全体の `status` も確認してください。回路全体の解析が短絡や入力不正で止まった場合も、基板の計器表示に数値は出ず、状態と理由を示します。

電流計を電源へ直接並列につなぐと短絡として解析され、読み値は理由とともに「—」になります。計器端子が未接続の場合も、値の代わりに状態を表示します。

交流波形・周波数スイープと時間波形でも、`unconnected` または `floating` の計器値は数値や波形として表示しません。周波数スイープは表示中の解析に使ったスイッチ状態を引き継ぎ、解析結果が更新されると以前のスイープを隠します。

理想電圧源や可変抵抗の0 Ω区間を含む並列経路によって電流計の電流が一意に決まらない場合も、アナログ解析は `floating` とします。

アナログ解析は分岐ごとの理想導線電流を計算しません。`wireCurrents` は空で、導線上の電流・電子の方向表示もありません。これは交流解析だけの仕様ではなく、拡張アナログ解析を使う直流回路でも同じです。導線分岐の電流は理想回路では一意に決まらない場合があるため、未計算値から方向を推測しません。従来7種類だけの直流回路は既存ソルバーの推定値を使います。

## 時間波形

`simulateTransient(document, options)` は `durationSeconds` と `timeStepSeconds` で指定した時間範囲の電圧・電流を返します。コンデンサ初期電圧とコイル初期電流、または直流動作点から開始できます。数値積分には後退Euler法を使い、交流電源は

```text
offsetVolts + √2 × voltageVolts(RMS) × cos(2π × frequencyHz × t + phaseDegrees × π / 180)
```

として時間波形を作ります。交流源の波形は表示用に丸める前の値を電圧制約として保持し、ピークとオフセットを合わせた最終電圧が有限かを確認します。初期位相の三角関数とRMSからピークへの正規化係数にはbinary64近似を使い、軸・45度近傍の微小な位相差と曲率は有理数展開で保持します。初期微分、微小刻み、通常区間は、この補正を含む同じ初期係数から求めます。45度軸では正規化係数を正確な±1とし、時間変化でこの軸を通る場合も同じ規則を使います。微小位相に90度を加減して丸める代わりに、整数の象限で係数を回転させます。

理想電圧源だけで閉じるループでは、直流電圧に加え、周波数ごとの振幅・位相・極性がKVLを満たすことを初期状態で確認します。サンプル時刻の電圧や初期微分が偶然一致していても、時刻間で矛盾する波形は `invalid` になります。非ゼロ振幅の理想交流源を短絡した場合も同様です。整合した電源ループでは、各電源を別々に三角関数評価した際の丸め差を接続矛盾とせず、独立な電源の拘束から各サンプルのループ電圧を求めます。直流オフセットの矛盾と、コンデンサの理想初期条件は厳密に検査します。

`|frequencyHz × Δt| < 1e-8` の時間区間では、前の厳密電圧に有理数Taylor展開で求めた増分を加え、短い最終区間と前の評価との整合性を保ちます。非ゼロ交流源の数をM、異なる周波数の数をNとし、この増分と初期位相の展開次数は `m = max(12, 2M + 4)` です。同一周波数でも複数の位相が相殺するため、次数は周波数の種類数だけでは決めません。初期微分も同じ次数・係数を使います。絶対位相は有理数のまま象限に還元します。複数周波数がある場合、還元角は `max(20, 2N + 16)` 次まで展開し、低次項の相殺後に残る高次応答を保持します。単一周波数でも微小還元角には20次展開を使い、軸と45度の近傍では正規化した係数から展開します。階乗と位相変化の積も有理数です。角度xに対する打切り誤差は、各係数の大きさに `|x|^(m+1)/(m+1)!` を掛けた値以下です。

度からラジアンへの変換には、独立したMachin式とChudnovsky式で確認したπの有理数近似を使います。精度は `b = min(512, 128 + 8M)` bitで、π自体の絶対誤差は `2^-b` 未満です。整数象限との位相差をbinary64のπで再構成して、相殺後の高次応答に偽の低次項を生じさせることを防ぎます。初期位相の補正と初期微分も同じ精度を使います。

単一周波数の通常区間はbinary64の三角関数をモデル境界とします。その際は `cos(x)-1 = -2 sin(x/2)^2` を使い、丸められた1に近いcosから1を引いて微小な2次応答を失うことを防ぎます。この境界は長い非線形解析の状態に高次有理数の分母を引き継ぎ続ける計算負荷も抑えます。三角係数・π近似・後退Euler法の離散化誤差は別に残り、大きな相殺や増幅がある回路では最終応答の誤差として評価してください。例では、部品を選び「時間波形・過渡解析」を開いて条件を指定します。

開始時刻 `t = 0` でも指定されたコンデンサ電圧とコイル電流を保ち、接続点の電流のつり合いから初期電圧・電流を求めます。コンデンサを含む理想電圧ループでは、枝の向きを含む `Σ(I_C/C)` と電圧源の微分値を足した制約から初期電流を分配します。交流源に直結されたコンデンサの初期電流も `I_C = C·dV/dt` から求めます。直列コイルには同じ電流変化率が流れるため、初期電圧はインダクタンスに応じて分かれます。例えば9 Vを1 Hと2 Hの直列コイルへ印加した場合は3 V・6 Vです。直列コイルの初期電流が一致しないなど、接続と矛盾する初期条件は `invalid` になります。`startFromOperatingPoint: true` を指定すると、まず直流動作点でコンデンサ電圧とコイル電流を求め、表示用に丸める前の厳密値を初期状態として保ちます。この設定では部品の `initialVoltageVolts` / `initialCurrentAmps` を初期条件に使わず、直流解析が選んだ保存状態を使います。交流電源はその直流オフセットを使った動作点から、`t = 0` の実波形へ切り替わります。実波形が保存したコンデンサ電圧などの理想初期条件と矛盾する場合は `invalid` になります。

```ts
import { createCircuitExample, simulateTransient } from "@nodemy-official/circuit-module";

const chargingCircuit = createCircuitExample("charging");
const waveform = simulateTransient(chargingCircuit, {
  durationSeconds: 0.01,
  timeStepSeconds: 0.000025,
  startFromOperatingPoint: false,
});
if (waveform.status === "valid") {
  console.log(waveform.samples.at(-1)?.parts.load?.voltageVolts);
}
```

React UIでは `CircuitSimulationPanel` が解析モード・周波数の設定と `CircuitTransientPanel` をまとめて表示します。`CircuitTransientPanel` は単独でも配置できます。

`CircuitEnergyPanel` の蓄積エネルギーは、保持された厳密な電圧・電流から計算します。抵抗・電球の累積消費エネルギーは、各サンプルの電圧と電流から求めた瞬時電力を台形則で積分し、累積値の表示時に丸めます。瞬時電力や各区間のエネルギーが表示用の `number` では0になっても、表現可能な累積値は保持します。これはサンプル間の台形近似であり、連続時間の厳密な積分ではありません。過渡結果の任意の `energyReadings` は解析時に集計した表示値で、入力値のスナップショットと、必要な場合は独立した `energyPrecisionExpressions` を持ちます。JSONやstructuredCloneで復元しても利用でき、部品係数・サンプル・共有式を編集した場合は再描画時に失効し、現在の読み値から再計算します。

```tsx
import { CircuitEditor, CircuitSimulationPanel } from "@nodemy-official/circuit-module/ui";

export function SimulationSettings() {
  return <CircuitEditor>{(editor) => (
    <CircuitSimulationPanel
      document={editor.document}
      analysis={editor.analysis}
      options={editor.analysisOptions}
      onChange={editor.setAnalysisOptions}
    />
  )}</CircuitEditor>;
}
```

`useCircuitEditor` の `analysisOptions` と `setAnalysisOptions(options)` は回路データから独立したセッション状態です。標準の `CircuitEditorLayout` はこの設定を解析パネルへ接続しています。過渡解析パネルは計算結果をその場で表示し、UI上限は2000時間ステップです。コアAPIにも `MAX_TRANSIENT_STEPS`、`MAX_TRANSIENT_SOLVER_WORK`、解析端子数512の上限があります。回路の端子数・時間刻み・期間により、演算量上限を超える解析は拒否されます。

## モデルの範囲と限界

- 抵抗・電球は定数抵抗です。温度による抵抗変化や熱連成はありません。
- ダイオードとLEDは温度一定のShockley式、BJTは簡易Ebers–Moll型、MOSFETはチャネル長変調を含む二乗則近似です。MOSFETのボディダイオード、接合・拡散容量などの寄生容量、温度依存、降伏には対応しません。
- 過渡解析ではコンデンサとコイルの蓄積状態を扱いますが、半導体は各時間ステップで準静的に解きます。半導体の電荷蓄積や逆回復はありません。
- 後退Euler法のコンパニオン係数・履歴値は内部で有理数を保持します。コイルの履歴積 `L·I` は表示用の電圧へ丸めず、有限な物理応答を途中のoverflowで拒否しません。ただし変換に使う `dt/C` または `L/dt` が有限で正の `number` に表現できない場合（0へのunderflowまたはoverflow）、過渡解析は `invalid` になります。
- オペアンプはGND基準で、利得と指定した正負電源レールを使う簡易3端子モデルです。出力抵抗は20 Ω固定で、電源レールの消費電流は算出しません。帯域幅、スルーレート、有限の供給電流、入力電流・オフセットは扱いません。
- 交流解析は単一周波数の定常小信号解析で、過渡波形や高調波歪みを返しません。過渡波形は別途 `simulateTransient` で計算します。
- 理想電源・導線のループや特異な接続、非線形方程式の未収束は解析不能になることがあります。診断と `status` を確認してください。

この分け方はSPICE系ツールで一般的な直流動作点、小信号交流、過渡解析の区別を参考にしています。モデル粒度は本パッケージの実装範囲に限られます。部品記号・端子の参考には[CircuitLab Circuit Elements](https://www.circuitlab.com/docs/circuit-elements/)、解析種別とSPICEの説明には[ngspice Tutorial](https://ngspice.sourceforge.io/ngspice-tutorial.html)と[ngspice User Manual](https://ngspice.sourceforge.io/docs/ngspice-manual.pdf)を参照してください。
